## 五、诚实边界（未完成 / 已知限制）

1. **密钥仍明文落盘**：本版做到了「前端不落明文」，但 `config.json` 里的 API Key 仍是明文。docs/05 里 M4 规划的 Windows DPAPI 加密**未实施**——避免加密后旧版读不到 Key、破坏回滚路径。设置→关于里也写明了。
2. **未做完整规划‑执行‑校验内核**：当前是「显式联网检索 → 结果注入上下文 → 模型整理」的单步工具循环 + @命令，不是 docs/05 §9 定义的多步自主规划。M5 的多模型按任务路由也未做。
3. **Skill 生态未升级**：仍是 v2.3.0 的 `/api/skills` 文件包机制，没有 manifest / 权限声明 / 沙箱。MCP Hub 的健康检查、工具级开关、命名空间未做。
4. **文心 / 混元未实测接入**：Provider Registry 里没有这两家预设（需各自鉴权实测），其余预设按官方 OpenAI 兼容地址配置，除讯飞 MaaS 外**未逐个发真实请求验证**。
5. **本机网络**：代理 `127.0.0.1:54869` 偶发对 CONNECT 返回 502 或挂起。后端已做自适应切换，但直连较慢（实测 13~23 秒）。首次请求偏慢属已知现象，不是配置错误。
6. **流式收尾**：讯飞发完 `data: [DONE]` 后不主动断连，后端在 DONE 处主动收尾；换到其他厂商若流格式不同，需再适配。
7. 冒烟覆盖「服务可起、端点可用、资源完整、真实浏览器点击发送」；**未覆盖**全部设置项的人肉交互、MCP 子进程联调、Office 六件套的真实文件操作（这些沿用 v2.3.0 已验证代码）。

## 六、隐私与出域

- 全程未上传任何本地内容；未使用本地文件作联网检索关键词；未写 E 盘。
- 验证用的网络请求只发往讯飞 MaaS 官方端点与本机 127.0.0.1。
- 模型调用与 `@web` 之外的功能全部本地执行；联网开关默认关闭，审计链区分「本地调用 / 联网调用」并只记类型、摘要与长度，不记会话正文、不记密钥。
- 破坏性操作（删会话、回滚文件、清空会话）一律二次确认。
