## 二、明早怎么用（三条零消耗路径）

双击 `builds\Super-Agient_v3.1.0.exe`。首次 SmartScreen 提示「未知发布者」→「仍要运行」（无代码签名，历史已知限制）。
讯飞星辰 MaaS 为可选 Provider 样例，需自行填写 API Key；**不填 Key，本地办公功能也全部可用**。

| 路径 | 操作 | 输出 |
|---|---|---|
| ① 直接说 | 输入框写 `帮我写一份家政服务技能培训方案，单位=示范中心 人数=30 导出为 PDF` | 自动生成完整方案 + PDF 文件卡片 + 5 步执行计划 + 零 token 徽章 |
| ② 本地办公面板 | 顶栏「本地办公」→ 选模板 → 填主题/参数 → 选格式 → 「本地预览」或「生成并导出」 | 可先预览全文再导出 8 种格式，支持复制全文 / 插入对话 |
| ③ 消息导出 | 任意回复右下角下载图标，或 `@文档 html` | 把对话内容另存为 Word / HTML / PDF / Excel / PPT / MD / TXT / CSV |

**参数写法**：`主题 单位=xxx 部门=xxx 人数=30 课时=240 地点=xxx 起止时间=xxx 目标=xxx 预算=xxx 撰写人=xxx`。
不填的字段一律显示为 `【待填：单位名称】` 之类占位符，**不会编造任何事实、数字或政策文号**。

**格式关键词**：说「导出为 PDF / HTML / Excel / PPT / Markdown / 纯文本 / CSV」会自动选对应格式，默认 Word。

### 3.2 新增模块

**`docgen.py` — 本地长文生成引擎（零模型调用）**
- 11 个模板：培训方案、项目实施方案、通用写作大纲、课程大纲、工作计划、工作总结、会议纪要、通知、调研报告、汇报稿、工作清单。
- 模板 = 章节骨架 + 参数槽，用 `SafeDict` 渲染，缺键自动出占位符；`_dedupe()` 消除「培训培训方案」这类拼接重复。
- `parse_args()` 从自然语言提取 `key=value` 与主题，剥离「帮我写一份」「，导出为 HTML」等噪声；不做任何联网或模型调用。
- `markdown_to_doc()` 把任意 Markdown（含对话内容）转成结构化 Doc，供导出复用。

**`office_skills.py` — 本地办公技能框架**
- 11 个技能统一注册（`manifest()` 返回技能/模板/格式/字段/输出目录），前端按清单自动渲染。
- 8 种格式渲染器：
  - `docx`：python-docx，宋体/黑体中文 eastAsia 字体、标题层级、表格 `Table Grid`、1.5 倍行距
  - `html`：**完全自包含**单页（内联 CSS + 内联机器人 SVG），无外部资源，带「打印 / 另存为 PDF」按钮与打印样式
  - `pdf`：PIL + 本机中文字体（微软雅黑/黑体/宋体）逐页绘制 A4@150dpi，自动换行、表格、页脚页码，**不依赖 Word 或云端转换**
  - `xlsx`：openpyxl，表头加粗填色、冻结首行、列宽自适应
  - `pptx`：python-pptx，封面 + 按章节生成内容页
  - `md` / `txt` / `csv`（UTF-8 BOM，Excel 直接打开）
- 输出目录 `~/.ai-super-agent/AI.Super-Agent/v3/output/`；文件名带 `_v31_日期` 与序号，**绝不覆盖旧文件**；文件名白名单清洗、禁止路径穿越。
- `GET /api/v3/output/<name>` 只在输出目录内取 basename 并返回附件。

### 3.3 Agent 增强

- `detectDocIntent()` 纯规则路由：命中「方案 / 大纲 / 总结 / 计划 / 纪要 / 通知 / 报告 / 汇报稿 / 清单」且有生成动词 → 走本地链；纯提问（「什么是培训方案」）不误触发。
- `detectFormat()` 从文本识别输出格式。
- `makePlan()` + `executeLocalDoc()`：**5 步执行计划**（意图识别 → 参数解析 → 模板渲染 → 格式导出 → 结果校验），逐步回填状态、耗时与说明，实时显示在消息里。
- 本地链失败时明确降级说明，不伪造文档、不偷偷改走云端。
- `runLocalCommand` 新增中文命令支持：`@方案` `@大纲` `@文档` `@office` `@skills3`；原 14 条命令全部保留。

### 3.4 UI

- 顶栏「本地办公」入口；欢迎页 4 张卡换成本地能力卡并加「零 token」徽章。
- 消息新增：执行计划卡片、文件卡片（下载 / 复制路径）、零消耗徽章、导出按钮。
- 设置「关于」页写明新分层、隐私边界、回滚路径与开发者信息。
- 侧栏品牌、头像、输入区文案、页面标题与 favicon 全部换成机器人与 Super-Agient。


## 七、诚实边界（未完成 / 已知限制）

1. **模板是骨架，不是行业定稿**：11 个模板提供规范章节与占位符，事实、数字、政策文号、人员信息一律留空由用户核对填入，本版不接入任何外部资料库自动补全。
2. **未做模型润色混合模式**：当前是「纯本地生成」与「纯云端问答」二选一，尚未实现「本地出骨架 → 模型只补写少量段落」的省 token 混合链路。
3. **多步自主规划仍有限**：执行计划是本地文档链路的固定 5 步，不是 docs/05 §9 定义的开放式多步规划-执行-校验内核；跨工具编排、自动重试策略未做。
4. **PDF 依赖本机中文字体**：从 `C:\Windows\Fonts` 找 msyh / simhei / simsun 等；若系统缺字体，`pdf.write` 会明确报错并建议改用 HTML / Word，不会静默输出乱码。
5. **PPT / Excel 是结构化简版**：PPT 按章节生成封面与内容页（不套企业模板），Excel 取文档第一张表格；复杂图表、样式母版未做。
6. **密钥仍明文落盘**（v3.0 遗留）：DPAPI 加密未做，避免破坏旧版回滚兼容。
7. **Provider 预设**：除讯飞 MaaS 外仍未逐个真实请求验证。
8. 冒烟覆盖「服务可起、端点可用、资源完整、真实浏览器点击发送 + 本地办公全链路」；**未覆盖**全部设置项的人肉交互、MCP 子进程联调、Office 六件套旧端点的真实文件操作（沿用 v3.0/v2.3.0 已验证代码）。
