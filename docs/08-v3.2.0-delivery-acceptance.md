## 六、模型任务指令协议（"模型派活，本机干活"）

模型不需要返回长文件正文，只需输出**短 JSON 指令块**，本机执行器负责真正的文件生成：

````text
```agent-task
{"skill":"pdf.to_docx","params":{"fileId":"20261115_xxxx","saveTo":"D:\\输出\\"},"note":"转成 Word"}
```
````

也支持 `@task {...}`、`{"tasks":[...]}`、每行一个 JSON 对象。**执行器约束**：

- 技能必须在 `skillhub.ALL_MAP` 白名单内，未知技能直接拒绝；
- `params` 上限 200 KB，单次最多 20 条指令，`fileIds` 最多 20 个；
- `saveTo / path / outputDir` 等路径字段**拒绝 URL / UNC**，只接受本机磁盘路径；
- 返回 `steps / files / summary / ms`，并在界面渲染任务卡片（每条指令的成败、耗时、落盘路径）。

云端问答时，系统会把可用技能清单与附件摘要注入系统提示；只有模型确实输出指令块才会执行，普通聊天不会触发。

## 七、文件上传与指定位置保存

**上传**：前端 `FileReader → base64 → /api/v3/files/upload`，支持点选与拖拽，单文件 ≤ 25 MB，解析文本上限 60000 字。解析库：PyPDF2 / python-docx / openpyxl / python-pptx / lxml / Pillow。

**保存**：`saveTo` 可填目录或完整文件名；`D://…`、`D:\…`、正斜杠写法均被规范化；同名文件自动加 `_2`、`_3`，**绝不覆盖**；路径拒绝 `http(s) / ftp / file / ws / wss / data / javascript` 与 `\\server\share` UNC。自定义目录产物由后端注册**本次会话一次性下载 token**回给前端，不暴露任意磁盘读取接口。

**隐私边界**：上传文件只落在本机应用数据目录；云端问答默认只注入**前 1500 字摘要**，界面有「摘要随对话发送」开关，关闭后附件内容一律不出本机。

## 十、诚实边界 / 已知限制

- **扫描版 PDF 与图片不做 OCR**：只返回「无法提取文本」与明确提示，**不伪造文本**；图片仅读取尺寸等元信息。
- **任务执行器不是通用自主 Agent**：它是「模型按约定输出短 JSON → 本机白名单执行」的协议，不支持任意代码、任意命令或自主多步规划。
- **云端链路沿用 v3.1 已验证通道**：本轮 43 + 10 项验收集中在本地新增能力，未重复做云端计费对话与模型质量评测；有 Key 时开放式问答仍会调用讯飞星辰 MaaS。
- 云端附件摘要默认开启、上限 1500 字，**关闭开关后仍需用户自行确认对话中不粘贴敏感原文**；应用不主动上传整份文件。
- 一次性下载 token 仅在**本次进程会话**内有效，重启应用后需重新生成。
- PDF 导出由 Pillow 绘制中文字体，依赖本机字体；换机器缺中文字体时可能显示方框。
- EXE 无代码签名，SmartScreen 会提示未知发布者。
- 源码目录 `src/v3.2.0/.cdp32/` 是浏览器测试 profile 残留（回收站清理失败），**不影响运行**，可手动删除。
- 测试产物集中在 `D:\work Buddy\.v32_test_out\`，**未清理**，与源码和成品隔离。
